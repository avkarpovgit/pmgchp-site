# Архив скриптов

Скрипты, выведенные из эксплуатации. Сохранены на случай возврата к прежнему процессу
(в активном пайплайне и в `.github/workflows/deploy.yml` не используются).

- `update_monitoring.py` — авто-импорт новых выпусков мониторинга из веб-версии
  телеграм-канала (`t.me/s/`) в `src/data/monitoring.json`. Выведен из работы в июле 2026:
  процесс стал **site-first** — выпуск сначала публикуется на сайте вручную, затем отдельно
  готовится текст поста для Telegram. Раньше запускался ежедневно из `deploy.yml`.
