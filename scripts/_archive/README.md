# Архив скриптов

Скрипты, выведенные из эксплуатации. Сохранены на случай возврата к прежнему процессу
(в активном пайплайне и в `.github/workflows/deploy.yml` не используются).

- `update_monitoring.py` — авто-импорт новых выпусков мониторинга из веб-версии
  телеграм-канала (`t.me/s/`) в `src/data/monitoring.json`. Выведен из работы в июле 2026:
  процесс стал **site-first** — выпуск сначала публикуется на сайте вручную, затем отдельно
  готовится текст поста для Telegram. Раньше запускался ежедневно из `deploy.yml`.

- `update_drafts.py` — ежедневный скрейпинг статусов законопроектов с СОЗД
  (`sozd.duma.gov.ru`) с автообновлением `status`/`stages` в `src/content/drafts/*.md`.
  Выведен из работы в июле 2026. Причина: СОЗД блокирует IP-адреса GitHub Actions — запросы
  отваливались по таймауту, авто-коммита статусов не было ни разу. Статусы ведутся вручную
  (см. README → «Статусы законопроектов»).
  **При возврате учесть два условия:** (1) нужен рабочий доступ к СОЗД с раннера — секрет
  `DUMA_PROXY` (http-прокси с РФ-IP); (2) в `detect_status` есть ложноположительный матч —
  паттерн «Принят Госдумой» ловит рутинную фразу «предложить принять законопроект…», из-за
  чего ранние стадии помечаются как принятые (регулярки нужно чинить, тесты — в `--selftest`).
